# Vela Atelier

A portfolio storefront for a fictional kitchen and bathroom brand. The site is here to show website development: catalogues, product pages, cart, consult booking, a planning studio, and scripted support chat.

Nothing is for sale. Studios, prices, and policies are made up.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Start the app: `npm run dev`
3. Open `http://localhost:3000`
